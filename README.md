# KiCad & Embedded Hardware Portfolio

KiCad를 활용해 USB PD 전원 공급 모듈 및 회로를 설계한 개인 하드웨어 포트폴리오입니다.

---

## 프로젝트 개요

### 1. Door Sensor Single Project (현관문 감지 알리미)
* **설명:** 하드웨어 회로 및 센서 구성을 위한 프로젝트[cite: 3]
* **주요 구성:** 마이크로컨트롤러(ESP32) 및 도어 센서 회로 구성[cite: 3]

### 2. USB-C PD Module (HUSB238)
* **설명:** HUSB238 컨트롤러 IC와 USB Type-C 리셉터클 커넥터를 활용한 전원 공급 모듈 회로 설계
* **주요 특징:** KiCad를 이용한 PCB 회로도 및 아트워크 설계 완료
